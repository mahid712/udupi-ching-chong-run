# ಉಡುಪಿ ಚಿಂಗ್ ಚಾಂಗ್ ರನ್ — The Udupi Ching Chong Run

> **Coastal Karnataka Arcade Runner (Udupi to Malpe Beach)**  
> 🌐 **Live Web Game:** [https://mahid712.github.io/udupi-ching-chong-run/](https://mahid712.github.io/udupi-ching-chong-run/)

An arcade highway runner through Coastal Karnataka. Sprint through the coastal highway from Udupi to Malpe Beach, dodge Udupi Cargo Express delivery tempos, jump barricades, weave through tight bus slaloms, and compete in the local multiplayer tournament for the fastest time to reach Malpe Beach!

---

## 🏆 Key Features

- **🎮 Multi-Player Tournament Mode:**
  - Choose between **Solo Run** or **Tournament Mode** (1 to 8 players).
  - Enter custom player names for every participant.
  - Turn-by-turn hotseat racing with active turn indicator badges.
  - Automatically records finish times and distance for every player.
  - **Tournament Leaderboard & Winner Podium:** The player who completes the run in the **least time** is crowned **Winner & Malpe Champion 🏆**!
  - Local persistence (`localStorage`) stores tournament history and personal bests.

- **🏃 5 Coastal Tulu-English Runners:**
  - **Ching Chong:** Coastal bullet runner, NH-66 speedster (`Speed: 1.15`).
  - **Vicky Malpe:** Malpe beach cheetah (`Speed: 1.08`).
  - **Shetty Anna:** Udupi hotel boss sprinting with bill receipt book (`Speed: 0.88`).
  - **Kavya Kudla:** Kudla express runner (*Enkulu Udupi daakulu*) with blue sash (`Speed: 0.98`).
  - **Banta:** Kambala champion sprinter (*Full power maare!*) (`Speed: 1.05`).

- **🌊 Malpe Beach Finish Line:**
  - Highway road transitions onto **golden Malpe sand** with a wooden beach boardwalk.
  - Shimmering **Arabian Sea waves** with rolling white surf.
  - **Malpe Coastal Lighthouse** standing 28m high with crimson red and white stripes and a glowing beacon light.
  - Traditional wooden coastal fishing boats (*ದೋಣಿ*) and seaside umbrellas.
  - Tropical coconut palm trees lining the beach promenade.

- **⚡ Gameplay & Obstacles:**
  - Dual bus slaloms at 330m and 398m with tight 11.5–12m reaction windows.
  - Dynamic Udupi Cargo delivery tempos (`KA 20 C 9999`) traveling down the highway with warning flashers.
  - Authentic Tulu voice & comic dialogue bursts (*BALPULE!*, *BALPULE MAARE!*, *ODE BALPUVA!*, *MUUL BALA MAGA!*, *ONJI CHURU MAARE!*, *HALF WAY MAARE!*).

- **🛑 100% Standalone & Client-Side:**
  - Built with pure HTML5 Canvas 2D + Web Audio API synthesizer.
  - Zero external servers, zero dependencies. Runs instantly in any modern browser.

## 🕹️ Controls

| Action | Keyboard | Touch / Mobile |
|---|---|---|
| **Move Left / Right** | <kbd>←</kbd> / <kbd>→</kbd> or <kbd>A</kbd> / <kbd>D</kbd> | Drag virtual joystick left / right |
| **Sprint / Back** | <kbd>↑</kbd> / <kbd>↓</kbd> or <kbd>W</kbd> / <kbd>S</kbd> | Drag virtual joystick up / down |
| **Jump** | <kbd>SPACE</kbd> | Tap the on-screen **JUMP** button |

## 🚀 How to Run Locally

Simply clone the repository and open `index.html` directly in your browser:

```bash
git clone https://github.com/mahid712/udupi-ching-chong-run.git
cd udupi-ching-chong-run
```

Double click `index.html` or open it with your favorite browser:
```bash
start index.html
```
